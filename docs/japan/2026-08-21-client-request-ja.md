# 8月21日フィードバック確認会のお願い

このたびは、具体的なフィードバックをお送りいただき、誠にありがとうございます。

ご指摘を受け、今回の課題を単純なAIモデルの性能差だけではなく、①検索条件の扱い、②台本作成前に必要な情報、③社内で承認された表現・構成の不足、④評価方法、の4点に分けて見直しました。

## 今回改善した内容

### 商品検索

- 価格帯、カテゴリー、対象チャネルなどの必須条件を、単なる優先条件ではなく除外条件として扱うようにしました。
- 条件外の商品で件数を埋めず、該当商品が少ない場合は少ないまま理由を確認できる設計にしました。
- 日本向けサービスでは、日本市場のデータのみを表示するように整理しました。
- 商品の出典、価格、カテゴリーなど、判断根拠を確認しやすくしました。

### 台本作成

- 商品を選択しただけで生成せず、放送時間、ターゲット、最重要メッセージ、実売価格、実演内容、避けたい表現、トーンを入力してから生成する流れに変更しました。
- 確認済みの商品情報と、AI調査による企画上の仮説を分けて扱うようにしました。
- 根拠のない専門家コメント、お客様の声、性能数値、価格、特典、実演内容を作らないよう制約を強化しました。
- 現在いただいている承認台本は1商品のみのため、その商品の固有情報を別商品へ転用しないようにしています。
- 生成に失敗した場合、原因と必要な対応が日本語で分かるようにしました。

なお、利用期間が長くなるだけでAIが自動的に改善されるわけではありません。精度を継続的に上げるには、御社に正解・不正解をご判断いただいた事例を蓄積し、同じ評価セットで改善前後を測定することが必要です。

## 当日ご相談したい評価方法

感覚的な比較ではなく、現在のツールと改善版へ同じ条件を入力し、ツール名を伏せて結果を比較したいと考えております。

商品検索では、必須条件の違反件数、上位5件の正解率、実務で確認する価値のある商品の割合を確認します。台本では、事実誤認、放送構成、御社らしい表現、修正に必要な時間、審査上のリスクを確認します。

まず「必須条件違反と根拠のない事実は0件」を共通の最低条件とし、それ以外の合格基準は当日すり合わせをお願いできればと思います。

## 事前にご提供をお願いしたい資料

### 商品検索用

可能であれば直近の実務事例20件、当日の比較用として最低10件をお願いいたします。

- 実際に入力した検索文
- 検索ごとの正解商品3～5件とURLまたは商品コード
- 表示してはいけない商品と、その理由
- 必ず守る条件（価格、カテゴリー、チャネル、季節、対象者など）
- 件数が少ない場合に緩和してよい条件
- 現在のツールで同じ検索をした際の上位5件
- 実際に採用した商品と、不採用理由

### 台本作成用

- 異なる商品カテゴリーの最終承認台本5件以上（可能であれば10件）
- 修正前の原稿と最終承認版のセット3件以上
- どこを、なぜ修正したかが分かるコメント
- 放送時間、コーナー順、出演者の役割、CTAの位置
- 商品仕様、機能、認証、試験結果と、それぞれの確認元
- 通常価格、放送価格、送料、特典、保証、適用期間
- 禁止表現、必須表記、社内審査チェックリスト
- 想定顧客、解決したい課題、必ず伝えたいメッセージ
- 実施可能な実演と、実施不可の実演

### 運用・費用判断用

- 実際の利用予定人数と役割
- 月間の商品検索件数と台本作成件数
- 現在、検索1件・台本1件にかかっている時間
- 初稿の採用率と、承認までの平均修正時間
- 現在のツールおよび汎用AIにかかる月額費用
- 1か月の検証後、継続利用を判断できる数値基準

- 正解データをご提供いただく担当者と日程
- 検索精度・台本品質の合格基準
