## 한 문장 피치

> MediaWorks가 이미 구축한 시장 수집 파이프라인을, 상품 후보를 찾는 시스템에서 실제 상품 선정과 매출 결과를 학습하는 Buyer Intelligence OS로 전환하자는 제안입니다.

일본어 핵심 문장:

> 市場データを集める仕組みから、商品判断と売上結果を学習する Buyer Intelligence OS へ進化させます。

## 반드시 피칭할 내용

### 1. 이미 데이터 기반은 만들어졌다

- 상품 후보 8,199건
- 방송 분석 2,561건
- 출처가 연결된 Evidence 1,315건
- 상품·카테고리 Insight Snapshot 182건
- 자사 매출·이익 데이터와 경쟁 방송 언어를 함께 분석할 수 있는 상태

전달 메시지:

> 지금은 새로 시작하는 프로젝트가 아니라, 이미 만들어진 데이터 자산을 실제 의사결정에 연결하는 단계입니다.

메인 문서: [현재 파이프라인 성숙도](./2026-09-04-mediaworks-data-insight-report.html#status)

### 2. 데이터에서 실제 사업 인사이트가 나오고 있다

- 의료·건강 지원은 MediaWorks 내부 이익과 경쟁 방송 적합성이 모두 높다.
- 청소·생활 문제 해결 상품은 Before/After 시연을 통해 재현 가능한 판매 구조를 만들기 쉽다.
- 골프는 높은 이익률과 계절성을 활용하는 단기 수익 영역이다.
- 숙면·침구는 경쟁 노출이 강하지만 내부 실적이 부족한 White Space 실험 영역이다.
- Live Fashion·Beauty는 후보는 많지만 가격과 방송 근거가 부족해 소규모 검증부터 해야 한다.

전달 메시지:

> 어떤 상품이 보이는지를 넘어, MediaWorks가 어디에 투자하고 어디는 작게 검증해야 하는지 구분할 수 있습니다.

메인 문서: [시장 기회 지도](./2026-09-04-mediaworks-data-insight-report.html#opportunity), [카테고리 실행안](./2026-09-04-mediaworks-data-insight-report.html#category-plan)

### 3. 카테고리마다 판매 방식이 다르다

- 패션은 디자인과 착용 편의가 먼저다.
- 뷰티는 효능, 사용 시연, 후기와 안전성 근거가 중요하다.
- 건강 상품은 효능만이 아니라 후기·인증·지속 가능성을 함께 제시해야 한다.
- Home·Kitchen과 가전은 사용 전후 변화와 조작·세척·관리 불안 해소가 핵심이다.

전달 메시지:

> 이 데이터는 상품 선정뿐 아니라 방송 대본, 시연 순서, 반론 처리 방식까지 재사용할 수 있습니다.

메인 문서: [Broadcast DNA](./2026-09-04-mediaworks-data-insight-report.html#dna)

### 4. 제안하는 제품은 세 가지다

1. **Weekly Buyer Cockpit**: 매주 근거가 있는 후보 10개와 부족한 근거를 보여준다.
2. **Stored-only Product Finder**: 저장된 근거만으로 동일한 조건에서 동일한 추천을 재현한다.
3. **Category Script DNA**: 카테고리별 판매 포인트, 증명 방식, 반론 처리 구조를 제공한다.

세 제품에서 발생한 채택·거절·샘플·방송·매출 결과는 다시 데이터로 돌아간다.

전달 메시지:

> 핵심 제품은 AI 채팅 화면이 아니라, Buyer가 근거를 보고 판단하고 그 결과가 다시 학습되는 업무 시스템입니다.

메인 문서: [목표 운영 모델](./2026-09-04-mediaworks-data-insight-report.html#target-model)

### 5. 90일 동안 내부에서 먼저 증명한다

- 30일: 담당자와 3개 카테고리를 정하고 판단 기록을 시작한다.
- 60일: 5축 Score, Knowledge Snapshot, Product Finder Beta를 만든다.
- 90일: 판단 100건, 실무 결과 20건, 재현 가능한 카테고리 승리 공식 1개를 확보한다.
- 90일 후 `GO / HOLD / STOP`을 판단한다.

전달 메시지:

> 대규모 구축이나 SaaS 판매를 먼저 제안하는 것이 아니라, 90일 안에 내부 효과를 수치로 증명하는 제안입니다.

메인 문서: [단계별 확장 계획](./2026-09-04-mediaworks-data-insight-report.html#expansion-roadmap), [90일 실행계획](./2026-09-04-mediaworks-data-insight-report.html#ninety-day-plan)

## 15분 피치 순서

| 시간 | 보여줄 화면 | 핵심 내용 | 목표 |
|---|---|---|---|
| 0–2분 | Hero + KPI | 이미 충분한 데이터 기반이 만들어졌음 | 프로젝트 신뢰 확보 |
| 2–4분 | 현재 성숙도 | 수집과 분석은 강하지만 실제 선정 결과가 0건 | 해결해야 할 핵심 문제 합의 |
| 4–7분 | Opportunity Map + Category Plan | 의료·청소·골프·숙면의 역할이 다름 | 데이터가 실제 결정을 만든다는 점 증명 |
| 7–9분 | Broadcast DNA | 상품 선정 데이터를 대본과 판매 구조로 확장 | 활용 범위 제시 |
| 9–11분 | Target Operating Model | Buyer Cockpit, Finder, Script DNA와 Feedback Loop | 제안 제품 명확화 |
| 11–13분 | Expansion Roadmap | 내부 검증 후 단계적으로 확장 | 위험이 통제된 계획 제시 |
| 13–15분 | 90-Day Plan | Owner, 3개 카테고리, 입력 의무, Test 예산 결정 요청 | 다음 행동 확정 |

## 미팅에서 요청할 결정사항

### 반드시 받아야 할 네 가지

1. **Owner 지정**: Buyer Intelligence 운영과 결과 기록을 책임질 한 명
2. **카테고리 선택**: 의료·청소를 기본으로 골프 또는 숙면을 포함한 3개 영역
3. **운영 규칙 승인**: 채택·거절 이유가 입력되지 않은 상품은 다음 단계로 진행하지 않음
4. **90일 Test 범위 승인**: MOQ, Sample, 재고, 방송·광고 비용의 상한 설정

미팅 종료 문장:

> 오늘 결정이 필요한 것은 SaaS 도입 여부가 아니라, 90일 동안 세 개 카테고리에서 판단과 결과를 연결해 볼 것인지입니다.

일본어:

> 本日決めていただきたいのはSaaS導入ではなく、3カテゴリで判断と結果をつなぐ90日間の実証を開始するかどうかです。

## 피해야 할 피칭

- **“AI가 잘 팔릴 상품을 자동으로 예측한다”**고 말하지 않는다.
- 경쟁사의 방송 횟수를 경쟁사 실제 매출로 설명하지 않는다.
- Product Finder가 이미 완성됐다고 말하지 않는다. 현재는 설계가 있으며 90일 계획에서 구현할 대상이다.
- 모든 영상과 모든 카테고리를 전수 분석하겠다고 약속하지 않는다.
- 90일 검증 전에 외부 SaaS 판매나 다중 고객 확장을 제안하지 않는다.
- 데이터 양, 크롤링 기술, AI 모델 이름을 피치의 중심에 두지 않는다.

대신 다음처럼 표현한다.

> 자동 예측이 아니라, 근거를 구조화하고 사람이 더 빠르고 일관되게 판단하도록 지원합니다.

## 예상 질문과 답변

### “AI 추천을 믿을 수 있습니까?”

현재 추천을 그대로 믿으라는 제안이 아니다. 모든 추천에 출처, 반증, 부족한 근거, Snapshot ID를 표시하고 Buyer가 최종 판단한다. 동일한 Snapshot에서는 결과가 재현되도록 만든다.

### “시간이 지나면 자동으로 더 똑똑해집니까?”

시간이나 데이터 수집만으로는 개선되지 않는다. 채택·거절 이유와 실제 샘플·방송·매출 결과가 누적되어야 MediaWorks에 맞는 판단 기준이 개선된다.

### “왜 경쟁 데이터 소스를 더 추가하지 않습니까?”

현재도 8,199개 후보와 2,561개 방송 분석이 있다. 지금의 병목은 데이터 부족이 아니라 상품 연결, 판단 기록, 결과 학습이다. 이 문제가 해결된 뒤 필요한 Source만 추가한다.

### “비용이 많이 증가하지 않습니까?”

현재 AI 비용보다 3.48TB 영상 저장과 2,600건 이상의 미완료 처리량이 더 큰 확장 위험이다. 전수 분석 대신 카테고리별 Quota와 대표 Sample을 적용하고, Backfill은 별도 Worker로 분리한다.

### “외부 고객에게도 판매할 수 있습니까?”

가능성은 있지만 지금은 아니다. 내부 ROI, 판단 100건, 실무 결과 20건, Product Finder, 고객별 데이터 격리가 완료된 뒤 2개사 이내 Pilot으로 검증한다.

메인 문서: [확장성 판단](./2026-09-04-mediaworks-data-insight-report.html#scale), [기술 가드레일](./2026-09-04-mediaworks-data-insight-report.html#technical-guardrails)
