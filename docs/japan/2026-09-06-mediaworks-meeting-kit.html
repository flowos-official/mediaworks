미팅 전후 사용 방법

  1. 준비: 발표자 대본을 먼저 읽고 고객용 보고서를 일본어로 엽니다.
  2. 발표: 고객용 보고서 창만 공유하고, 본인 화면이나 인쇄물에서 대본을 확인합니다.
  3. 질의응답: 대본의 예상 질문과 고객 보고서의 상세 내용을 참고합니다.
  4. 전달: 고객에게는 보고서 HTML 또는 해당 보고서에서 저장한 PDF를 전달합니다. 발표 대본과 이 자료 모음은 내부 준비용입니다.

발표 메시지의 배경과 상세 판단 기준은 내부 피치 가이드 원문에서 확인할 수 있습니다. 실제 발표 순서는 최신 발표자 HTML을 기준으로 하세요.
