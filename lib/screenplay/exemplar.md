1. **The Hook & Problem Setup (Act 1)**: `problem_framing_patterns`（隠れた危険性）を適用。専門家（衛生管理専門家）の権威付け（`authority_signal_patterns`）により、「普段の掃除ではカビや菌が落ちていない」という恐怖を煽り、解決策としての製品を提示。
2. **Studio Intro & Contrast (Act 2)**: 従来品の大型スチームクリーナーを先に見せることで、新商品の「680gの軽さ」「コードレス」という物理的優位性を際立たせるコントラスト手法（`rhetorical_devices`）を使用。MCのリアクションには指定のオノマトペや感嘆符（軽っ！！）を多用。
3. **The Live Demonstrations (Act 3)**: `demonstration_patterns`（ハイコントラスト・リビール）を適用。ギトギトの油汚れがスチームで瞬時に溶け、サッと拭き取ってピカピカのステンレスが露出する視覚的証明（High-Contrast Reveal）を実施。
4. **Objection Handling (Act 4)**: 「コードレスはすぐ充電が切れるのでは？」という視聴者の疑問（`objection_handling_patterns`）に対し、「大容量バッテリーで15分連続使用」という具体的数値（`number_and_metric_patterns`）で即座に反論。
5. **The Value Stack & Price Reveal (Act 5)**: `price_reveal_patterns`（バリュースタック）を完全再現。ベース価格提示 → ボーナス1付与 → ボーナス2付与（金額明示） → 合計小売価格提示（27,760円） → 「お値段そのまま（14,800円）！」という劇的な値下げフレーズ（`generation_template`の必須要件）を採用。
6. **Social Proof / VTR Testimonial (Act 6)**: `social_proof_patterns`を適用。自分は綺麗にしていると思っている顧客（片岡さん）が、真っ黒になったパッドを見て驚愕する（いやだ〜〜怖すぎますね…）という、共感と恐怖を誘うリアルな第三者評価を配置。※個人の感想です（コンプライアンス遵守）。
