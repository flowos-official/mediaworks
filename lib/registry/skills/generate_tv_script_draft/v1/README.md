# generate_tv_script_draft · v1

Per-product 30-second Japanese TV-shopping script generator. Used by the discovery enrichment pipeline as a separate Gemini call (split out from `enrich_product` so the agent doesn't spend its tool budget composing copy).

## Output

Free-text Japanese script (numbered sections, ≤300 chars).
